# Lamarck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent harness whose whole architecture is a typed genome that an Opus "engineer" rewrites from the harness's own failures, gated by train/held-out evals, with every version and run in MongoDB Atlas.

**Architecture:** A genome-driven RLM-style harness (`harness.py`) runs Gemini 3.8 Flash workers over a synthetic log-analytics workload (`tasks.py`), each task in its own spawned process (`pool.py`, `worker.py`). `cli.py evolve` loops: engineer proposes typed patches via headless `claude -p` → candidates evaluated on train → pure gate rule (`gate.py`) → held-out gate split → accept/reject, all recorded in MongoDB (`store.py`). A FastAPI page renders the lineage by polling MongoDB.

**Tech Stack:** Python 3.12 · uv-managed `.venv` · `google-genai` · `pymongo` · `pydantic` v2 · `fastapi` + `uvicorn` · `python-dotenv` · `pytest` · Claude Code CLI (`claude -p`) for the engineer.

**Spec:** `docs/superpowers/specs/2026-10-11-lamarck-design.md`

## Global Constraints

- Python 3.12. All dependencies live in `./.venv` created by `uv`; nothing is installed system-wide.
- Dependency versions are resolved with `--exclude-newer 2026-09-27` (at least 2 weeks old) and frozen to `requirements.txt`.
- Every install command is blocked by the user's dependency-gate hook until the user runs `touch ~/.claude/dependency-gate.allow` (one command per touch, 15-minute window). Show the exact command and ask first.
- Secrets live only in `.env` (mode 600, gitignored): `GEMINI_API_KEY`, `MONGODB_URI`. Never print, log or commit them. `start.txt` is gitignored.
- Worker model: `gemini-3.8-flash` ($0.75 / $3.75 per M input/output). Engineer: `claude-opus-5-5` via `claude -p` with `CLAUDECODE` unset.
- Protected (no genome op can change them): base prompt, scorer, task data, `TASK_TIMEOUT_S = 420`, `STEP_TIMEOUT_S = 60`, `TOKEN_CEILING = 3_000_000`, `max_steps ≤ 30`, `max_subcalls ≤ 200`.
- All state in MongoDB Atlas sandbox, database `lamarck`: `genomes`, `runs`, `feed`, `meta`.
- Run tests with `.venv/bin/python -m pytest -q` from the repo root.
- Everything is built today; the README says so.

## Review Focus

1. A worker reply with neither code nor `FINAL`, a ```` ```py ````/```` ```repl ```` fence, or `**FINAL:** x` markdown must be parsed or nudged, never crash the run. → Task 4 tests `test_fences_and_markdown_final_parse`, `test_prose_reply_is_nudged`.
2. Model code that hangs or prints megabytes must time out and be truncated; a hung task process must be killed. → Task 4 `test_repl_step_timeout`, `test_clip`; Task 5 `test_a_hung_job_is_killed_and_reported`.
3. Engineer output that is schema-valid but semantically invalid (unknown path, `context_mode="repl"` without `repl`, a skill that does not define its function, a syntax error, a no-op patch) must become an `invalid` candidate with a reason, and the loop continues. → Task 3 tests; Task 9 `test_propose_gives_up_after_two_invalid_answers`.
4. Loosely phrased answers ("The answer is 42.", "**Checkout**", "u0001 and u0002", "1,234") must be normalized before scoring. → Task 1 `test_score_tolerates_loose_phrasing`.
5. Gemini 429/503 bursts under 16 parallel workers must back off and retry rather than count as wrong answers. → Task 2 `test_with_retries_*`.

"""Deterministic synthetic workload: questions over production-style service logs.

Ground truth comes from the generated records, never from parsing the text, so scoring is exact.
Event messages are paraphrased several ways, so answering needs semantic judgment, not one regex.
"""
from __future__ import annotations

import random
import re
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from typing import Any

from lamarck import config

SERVICES = ["gateway", "auth", "checkout", "payments", "search", "inventory", "profile", "notifications"]
KINDS = ["needle", "topk", "distinct", "pairs"]
OK_STATUSES = [200, 200, 200, 201, 204]
OK_MSGS = ["request completed", "served {n} items", "cache hit for key k{n}", "rendered page in {ms}ms",
           "health check passed", "returned {n} results", "session refreshed", "wrote {n} rows"]
EVENTS: dict[str, tuple[list[int], list[str]]] = {
    "timeout": ([504, 503, 500], ["upstream timed out after {ms}ms", "deadline exceeded calling {svc2}",
                                  "no response from {svc2} within {ms}ms", "request to {svc2} took too long, aborting",
                                  "context deadline exceeded", "gave up waiting for {svc2} after {ms}ms"]),
    "ratelimit": ([429, 429, 503], ["rate limit exceeded for client", "too many requests, slow down",
                                    "quota exhausted for user", "throttled: {n} req/s over limit",
                                    "request shed by limiter"]),
    "decline": ([402, 400], ["card declined by issuer", "insufficient funds", "payment authorization refused",
                             "issuer rejected charge code PD-{code}", "charge blocked by fraud rules"]),
    "db": ([500, 503], ["connection pool exhausted", "deadlock detected, rolling back",
                        "replica lag too high, refusing read", "could not connect to primary",
                        "too many open cursors"]),
    "authfail": ([401, 403], ["invalid credentials", "token expired", "signature mismatch on JWT", "session revoked"]),
    "notfound": ([404], ["no such item i{n}", "route not found", "unknown sku s{n}"]),
}
EVENT_WEIGHTS = {"timeout": 6, "ratelimit": 5, "decline": 4, "db": 4, "authfail": 4, "notfound": 5}
EVENT_SERVICES = {"decline": ["payments", "checkout"]}
EVENT_RATE = 0.28
CATEGORY_WORDS = {"timeout": "timeout failure", "ratelimit": "rate-limiting or throttling error",
                  "authfail": "authentication or authorization failure", "db": "database error"}
DISTINCT_CATS = ["ratelimit", "authfail", "timeout", "db"]
START = datetime(2026, 10, 11, tzinfo=timezone.utc)
SPAN_S = 6 * 3600

TRACE_RE = re.compile(r"\b[0-9a-f]{12}\b")
USER_RE = re.compile(r"\bu\d{4}\b")
INT_RE = re.compile(r"-?\d+")


@dataclass(frozen=True)
class Task:
    id: str
    split: str
    idx: int
    kind: str
    question: str
    context: str
    answer: Any


def _at(rng: random.Random, lo: float = 0.0, hi: float = SPAN_S) -> datetime:
    return START + timedelta(seconds=rng.uniform(lo, hi))


def _record(rng: random.Random, at: datetime, users: list[str], cat: str | None = None, svc: str | None = None) -> dict:
    if cat is None:
        cat = "ok" if rng.random() >= EVENT_RATE else rng.choices(list(EVENT_WEIGHTS), weights=list(EVENT_WEIGHTS.values()))[0]
    if cat == "ok":
        status, template = rng.choice(OK_STATUSES), rng.choice(OK_MSGS)
    else:
        statuses, templates = EVENTS[cat]
        status, template = rng.choice(statuses), rng.choice(templates)
    svc = svc or rng.choice(EVENT_SERVICES.get(cat, SERVICES))
    msg = template.format(n=rng.randrange(1, 500), ms=rng.randrange(800, 30000),
                          svc2=rng.choice(SERVICES), code=rng.randrange(1000, 9000))
    dur = rng.randrange(800, 30000) if cat == "timeout" else rng.randrange(3, 900)
    return {"at": at, "svc": svc, "status": status, "user": rng.choice(users),
            "trace": f"{rng.getrandbits(48):012x}", "dur": dur, "msg": msg, "cat": cat}


def _fmt(r: dict) -> str:
    return (f'{r["at"]:%Y-%m-%dT%H:%M:%S}Z svc={r["svc"]} status={r["status"]} user={r["user"]} '
            f'trace={r["trace"]} dur_ms={r["dur"]} msg="{r["msg"]}"')


def _ask_needle(rng, recs, users, idx):
    code = rng.randrange(9000, 10000)  # ordinary decline codes are 1000-8999, so this one is unique
    target = _record(rng, _at(rng, 0.1 * SPAN_S, 0.9 * SPAN_S), users, cat="decline", svc="payments")
    target["msg"], target["status"] = f"issuer rejected charge code PD-{code}", 402
    recs.append(target)
    return (f"What is the trace id of the request in which the card issuer rejected charge code PD-{code}? "
            "Answer with the trace id only.", target["trace"])


def _ask_topk(rng, recs, users, idx):
    h = rng.randrange(0, 5)
    lo, hi = START + timedelta(hours=h), START + timedelta(hours=h + 2)
    counts = {s: 0 for s in SERVICES}
    for r in recs:
        if r["cat"] == "timeout" and lo <= r["at"] < hi:
            counts[r["svc"]] += 1
    target = rng.choice(SERVICES)
    rival = max(c for s, c in counts.items() if s != target)
    for _ in range(max(0, rival + 2 - counts[target])):  # unique winner by a margin of at least 2
        recs.append(_record(rng, _at(rng, h * 3600, (h + 2) * 3600 - 1), users, cat="timeout", svc=target))
    return (f"Between {h:02d}:00 and {h + 2:02d}:00 UTC, which service logged the most timeout failures "
            "(any wording, any status code)? Answer with the service name only.", target)


def _ask_distinct(rng, recs, users, idx):
    cat = DISTINCT_CATS[(idx // len(KINDS)) % len(DISTINCT_CATS)]
    n = len({r["user"] for r in recs if r["cat"] == cat})
    return (f"How many distinct users experienced at least one {CATEGORY_WORDS[cat]} "
            "(any service, any wording, any status code)? Answer with a single integer.", n)


def _ask_pairs(rng, recs, users, idx):
    both = sorted({r["user"] for r in recs if r["cat"] == "decline"} & {r["user"] for r in recs if r["cat"] == "timeout"})
    if not both:
        u = rng.choice(users)
        for cat in ("decline", "timeout"):
            r = _record(rng, _at(rng), users, cat=cat)
            r["user"] = u
            recs.append(r)
        both = [u]
    return ("Which users had at least one payment decline AND at least one timeout failure "
            "(any service, any wording)? Answer with the user ids as a comma-separated list.", both)


ASK = {"needle": _ask_needle, "topk": _ask_topk, "distinct": _ask_distinct, "pairs": _ask_pairs}


def make_task(split: str, idx: int, n_lines: int | None = None) -> Task:
    n_lines = n_lines or config.SPLITS[split][1]
    rng = random.Random(f"lamarck:{split}:{idx}:{n_lines}")
    kind = KINDS[idx % len(KINDS)]
    users = [f"u{n:04d}" for n in rng.sample(range(10000), max(40, n_lines // 10))]
    recs = [_record(rng, _at(rng), users) for _ in range(n_lines)]
    question, answer = ASK[kind](rng, recs, users, idx)
    recs.sort(key=lambda r: r["at"])
    return Task(id=f"{split}-{idx}-{n_lines}", split=split, idx=idx, kind=kind, question=question,
                context="\n".join(_fmt(r) for r in recs), answer=answer)


def score(task: Task, answer: str) -> float:
    a = (answer or "").lower()
    if task.kind == "needle":
        return float(set(TRACE_RE.findall(a)) == {task.answer})
    if task.kind == "topk":
        return float({s for s in SERVICES if re.search(rf"\b{s}\b", a)} == {task.answer})
    if task.kind == "distinct":
        nums = INT_RE.findall(a.replace(",", ""))
        return float(bool(nums) and int(nums[0]) == task.answer)
    got, want = set(USER_RE.findall(a)), set(task.answer)
    tp = len(got & want)
    if tp == 0:
        return 0.0
    p, r = tp / len(got), tp / len(want)
    return round(2 * p * r / (p + r), 4)
```

```python
"""Provider calls: Gemini workers through the raw API; the engineer through headless Claude Code."""
from __future__ import annotations

import json
import os
import random
import subprocess
import tempfile
import time
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Callable

from lamarck import config

RETRYABLE_CODES = {408, 429, 500, 502, 503, 504}
RETRYABLE_NAMES = {"ConnectError", "ConnectTimeout", "ReadTimeout", "ReadError", "RemoteProtocolError",
                   "WriteError", "PoolTimeout"}


@dataclass
class Turn:
    role: str  # "user" | "model"
    text: str
    raw: Any = None  # provider-native content of a model turn (keeps Gemini thought signatures)


def is_retryable(e: BaseException) -> bool:
    return getattr(e, "code", None) in RETRYABLE_CODES or type(e).__name__ in RETRYABLE_NAMES


def with_retries(fn: Callable[[], Any], attempts: int = 6, base_s: float = 2.0,
                 sleep: Callable[[float], None] = time.sleep) -> Any:
    for i in range(attempts):
        try:
            return fn()
        except Exception as e:
            if not is_retryable(e) or i == attempts - 1:
                raise
            sleep(min(60.0, base_s * 2 ** i) * (0.5 + random.random()))
    raise AssertionError("unreachable")


class GeminiClient:
    def __init__(self, api_key: str):
        from google import genai
        from google.genai import types

        self._types = types
        self._client = genai.Client(api_key=api_key)

    def generate(self, model: str, system: str, history: list[Turn], thinking_level: str) -> tuple[str, Any, dict]:
        types = self._types
        contents = [t.raw if t.role == "model" and t.raw is not None
                    else types.Content(role=t.role, parts=[types.Part(text=t.text)]) for t in history]
        cfg = types.GenerateContentConfig(system_instruction=system, max_output_tokens=16384,
                                          thinking_config=types.ThinkingConfig(thinking_level=thinking_level))
        resp = with_retries(lambda: self._client.models.generate_content(model=model, contents=contents, config=cfg))
        cand = resp.candidates[0] if resp.candidates else None
        raw = cand.content if cand is not None and cand.content and cand.content.parts else None
        text = "".join(p.text for p in (raw.parts if raw else [])
                       if getattr(p, "text", None) and not getattr(p, "thought", False))
        um = resp.usage_metadata
        tin = (um.prompt_token_count or 0) if um else 0
        tout = ((um.candidates_token_count or 0) + (um.thoughts_token_count or 0)) if um else 0
        return text, raw, {"in": tin, "out": tout}


class EngineerError(RuntimeError):
    pass


def claude_command(schema: dict, system_file: Path) -> list[str]:
    return [config.CLAUDE_BIN, "-p", "--model", config.ENGINEER_MODEL, "--effort", config.ENGINEER_EFFORT,
            "--system-prompt-file", str(system_file), "--tools", "", "--strict-mcp-config",
            "--setting-sources", "project", "--disable-slash-commands", "--no-session-persistence",
            "--output-format", "json", "--json-schema", json.dumps(schema)]


def claude_env() -> dict[str, str]:
    drop = {"CLAUDECODE", "GEMINI_API_KEY", "MONGODB_URI"}
    return {k: v for k, v in os.environ.items() if k not in drop}


def claude_json(prompt: str, system: str, schema: dict, timeout_s: int = 900) -> dict:
    with tempfile.TemporaryDirectory(prefix="lamarck-eng-") as d:
        system_file = Path(d, "system.md")
        system_file.write_text(system)
        proc = subprocess.run(claude_command(schema, system_file), input=prompt, capture_output=True, text=True,

"""The genome: everything about the harness the evolver may change, plus typed patches over it."""
from __future__ import annotations

import ast
import json
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field, ValidationError, model_validator

from lamarck import config

OP_NAMES = ("set", "add_note", "remove_note", "put_skill", "del_skill", "put_validator", "del_validator")
SETTABLE = {"root_model", "sub_model", "thinking_level", "context_mode", "repl", "max_obs_chars",
            "limits.max_steps", "limits.max_subcalls"}
MAX_NOTES, MAX_NOTE_CHARS, MAX_SKILLS, MAX_VALIDATORS, MAX_SOURCE_CHARS = 12, 500, 8, 4, 6000


class PatchError(ValueError):
    pass


class Limits(BaseModel):
    model_config = ConfigDict(extra="forbid")
    max_steps: int = Field(12, ge=1, le=30)
    max_subcalls: int = Field(40, ge=0, le=200)


def _check_source(name: str, src: str, must_define: str) -> None:
    if not name.isidentifier():
        raise ValueError(f"{name!r} is not a valid Python identifier")
    if len(src) > MAX_SOURCE_CHARS:
        raise ValueError(f"{name}: source longer than {MAX_SOURCE_CHARS} chars")
    try:
        tree = ast.parse(src)
    except SyntaxError as e:
        raise ValueError(f"{name}: syntax error: {e}") from None
    if not any(isinstance(n, ast.FunctionDef) and n.name == must_define for n in tree.body):
        raise ValueError(f"{name}: source must define a top-level function {must_define}()")


class Genome(BaseModel):
    model_config = ConfigDict(extra="forbid")
    root_model: str = config.DEFAULT_WORKER
    sub_model: str = config.DEFAULT_WORKER
    thinking_level: str = config.THINKING_LEVELS[0]
    context_mode: Literal["inline", "repl", "both"] = "inline"
    repl: bool = False
    max_obs_chars: int = Field(4000, ge=200, le=50000)
    system_notes: list[str] = Field(default_factory=list)
    skills: dict[str, str] = Field(default_factory=dict)
    validators: dict[str, str] = Field(default_factory=dict)
    limits: Limits = Field(default_factory=Limits)

    @model_validator(mode="after")
    def _consistent(self) -> "Genome":
        for m in (self.root_model, self.sub_model):
            if m not in config.WORKER_MODELS:
                raise ValueError(f"unknown worker model {m!r}; allowed: {sorted(config.WORKER_MODELS)}")
        if self.thinking_level not in config.THINKING_LEVELS:
            raise ValueError(f"thinking_level must be one of {config.THINKING_LEVELS}")
        if self.context_mode != "inline" and not self.repl:
            raise ValueError("context_mode 'repl' or 'both' requires repl=true")
        if len(self.system_notes) > MAX_NOTES or any(len(n) > MAX_NOTE_CHARS for n in self.system_notes):
            raise ValueError(f"at most {MAX_NOTES} notes of at most {MAX_NOTE_CHARS} chars")
        if len(self.skills) > MAX_SKILLS or len(self.validators) > MAX_VALIDATORS:
            raise ValueError(f"at most {MAX_SKILLS} skills and {MAX_VALIDATORS} validators")
        for name, src in self.skills.items():
            _check_source(name, src, must_define=name)
        for name, src in self.validators.items():
            _check_source(name, src, must_define="check")
        return self


GEN0 = Genome()


class Op(BaseModel):
    model_config = ConfigDict(extra="forbid")
    op: Literal["set", "add_note", "remove_note", "put_skill", "del_skill", "put_validator", "del_validator"]
    path: str | None = None
    value_json: str | None = None
    text: str | None = None
    index: int | None = None
    name: str | None = None
    source: str | None = None


def _need(o: Op, *fields: str) -> None:
    missing = [f for f in fields if getattr(o, f) is None]
    if missing:
        raise PatchError(f"op {o.op} needs {', '.join(missing)}")


def apply(genome: Genome, ops: list[Op]) -> Genome:
    if not ops:
        raise PatchError("empty patch")
    d = genome.model_dump()
    for o in ops:
        if o.op == "set":
            _need(o, "path", "value_json")
            if o.path not in SETTABLE:
                raise PatchError(f"path {o.path!r} is not settable; settable: {sorted(SETTABLE)}")
            try:
                value = json.loads(o.value_json)
            except json.JSONDecodeError as e:
                raise PatchError(f"value_json is not valid JSON: {e}") from None
            *parents, leaf = o.path.split(".")
            target = d
            for p in parents:
                target = target[p]
            target[leaf] = value
        elif o.op == "add_note":
            _need(o, "text")
            d["system_notes"].append(o.text)
        elif o.op == "remove_note":
            _need(o, "index")
            if not 0 <= o.index < len(d["system_notes"]):
                raise PatchError(f"no note at index {o.index}")
            d["system_notes"].pop(o.index)
        elif o.op in ("put_skill", "put_validator"):
            _need(o, "name", "source")
            d["skills" if o.op == "put_skill" else "validators"][o.name] = o.source
        else:
            _need(o, "name")
            bucket = d["skills" if o.op == "del_skill" else "validators"]
            if o.name not in bucket:
                raise PatchError(f"no {o.op.removeprefix('del_')} named {o.name!r}")
            del bucket[o.name]
    try:
        child = Genome.model_validate(d)
    except ValidationError as e:
        raise PatchError(str(e)) from None
    if child == genome:
        raise PatchError("patch does not change the genome")
    return child
```

"""Runs one task under one genome: the RLM text protocol over a persistent Python REPL."""
from __future__ import annotations

import ast
import contextlib
import io
import re
import signal
import threading
import traceback
from concurrent.futures import ThreadPoolExecutor
from dataclasses import dataclass, field
from typing import Any

from pydantic import BaseModel

from lamarck import config
from lamarck.genome import Genome
from lamarck.llm import Turn
from lamarck.tasks import Task, score

# --- protected: no genome op can change anything in this block --------------------------------
BASE_PROMPT = """You are a careful analyst answering one question about a dataset.

{mode}

End your work with a line of the form
FINAL: <answer>
where <answer> is only the answer: a name, a number, an id, or a comma-separated list.{notes}"""

MODE_INLINE = "The dataset is in the user's message. Read it carefully and reason step by step before answering."

MODE_REPL = """You have a persistent Python REPL. To run code, reply with a fenced block:
```python
print(...)
```
The printed output (cut to {max_obs_chars} characters) comes back in the next message. Variables persist between steps. Only the Python standard library is available.

In the REPL:
{context_line}- llm_query(prompt: str) -> str: asks a sub-model, which sees only the prompt you pass.
- llm_query_batch(prompts: list[str]) -> list[str]: the same, run in parallel.
{skills}
You may also finish with FINAL_VAR(name) to answer with the value of a REPL variable.
Budget: {max_steps} replies and {max_subcalls} sub-model calls."""

SUB_SYSTEM = "Answer the request precisely and concisely."
LIMIT_MESSAGE = "Step limit reached. Reply now with only 'FINAL: <best answer>'."
MAX_VALIDATOR_REJECTIONS = 2
# -----------------------------------------------------------------------------------------------

CODE_RE = re.compile(r"```(?:python|py|repl)?[ \t]*\n(.*?)```", re.S)
FINAL_VAR_RE = re.compile(r"FINAL_VAR\(\s*([A-Za-z_]\w*)\s*\)")
FINAL_RE = re.compile(r"^[\s*_#]*FINAL[\s*_]*:[\s*_]*(.+?)[\s*_]*$", re.M)


@dataclass
class Usage:
    by_model: dict[str, list[int]] = field(default_factory=dict)
    lock: threading.Lock = field(default_factory=threading.Lock, repr=False)

    def add(self, model: str, u: dict) -> None:
        with self.lock:
            m = self.by_model.setdefault(model, [0, 0])
            m[0] += u.get("in", 0)
            m[1] += u.get("out", 0)

    @property
    def tokens_in(self) -> int:
        return sum(v[0] for v in self.by_model.values())

    @property
    def tokens_out(self) -> int:
        return sum(v[1] for v in self.by_model.values())

    def cost(self) -> float:
        total = 0.0
        for model, (tin, tout) in self.by_model.items():
            pin, pout = config.WORKER_MODELS.get(model, (0.0, 0.0))
            total += tin / 1e6 * pin + tout / 1e6 * pout
        return total


class RunResult(BaseModel):
    task_id: str
    split: str
    kind: str
    question: str
    expected: Any
    answer: str
    score: float
    tokens_in: int = 0
    tokens_out: int = 0
    cost: float = 0.0
    steps: int = 0
    subcalls: int = 0
    error: str | None = None
    trace: list[dict] = []


def clip(s: str, n: int) -> str:
    return s if len(s) <= n else s[:n] + f"\n...[cut {len(s) - n} chars]"


def error_result(task: Task, message: str) -> RunResult:
    return RunResult(task_id=task.id, split=task.split, kind=task.kind, question=task.question,
                     expected=task.answer, answer="", score=0.0, error=message)


class StepTimeout(BaseException):  # BaseException so model code's `except Exception` cannot swallow it
    pass


class Repl:
    """Persistent namespace. run() returns printed output, a trailing expression's repr, or the error."""

    def __init__(self, ns: dict, step_timeout: float):
        self.ns, self.step_timeout = ns, step_timeout

    def run(self, code: str) -> str:
        buf = io.StringIO()
        use_alarm = threading.current_thread() is threading.main_thread()
        if use_alarm:
            def _alarm(signum, frame):
                raise StepTimeout(f"step exceeded {self.step_timeout}s")
            old = signal.signal(signal.SIGALRM, _alarm)
            signal.setitimer(signal.ITIMER_REAL, self.step_timeout)
        try:
            with contextlib.redirect_stdout(buf), contextlib.redirect_stderr(buf):
                tree = ast.parse(code)
                last = tree.body.pop() if tree.body and isinstance(tree.body[-1], ast.Expr) else None
                exec(compile(tree, "<repl>", "exec"), self.ns)
                if last is not None:
                    value = eval(compile(ast.Expression(last.value), "<repl>", "eval"), self.ns)
                    if value is not None:
                        print(repr(value))
        except StepTimeout as e:
            buf.write(f"\nTimeoutError: {e}\n")
        except BaseException:  # noqa: BLE001 — model code may raise anything, including SystemExit
            buf.write(traceback.format_exc(limit=-3))
        finally:
            if use_alarm:
                signal.setitimer(signal.ITIMER_REAL, 0)
                signal.signal(signal.SIGALRM, old)
        return buf.getvalue()


def _doc_line(src: str, name: str) -> str:
    for node in ast.parse(src).body:
        if isinstance(node, ast.FunctionDef) and node.name == name:
            doc = (ast.get_docstring(node) or "").strip().splitlines()
            return f"- {name}({', '.join(a.arg for a in node.args.args)}): {doc[0] if doc else ''}"
    return f"- {name}()"


def build_system(genome: Genome, task: Task) -> str:
    notes = "".join(f"\n- {n}" for n in genome.system_notes)
    notes = f"\n\nRules:{notes}" if notes else ""
    if not genome.repl:
        return BASE_PROMPT.format(mode=MODE_INLINE, notes=notes)
    n_lines = task.context.count("\n") + 1
    context_line = (f"- context: str, the dataset ({len(task.context)} characters, {n_lines} lines).\n"
                    if genome.context_mode != "inline" else "")
    skills = "".join(_doc_line(src, name) + "\n" for name, src in genome.skills.items())
    mode = MODE_REPL.format(max_obs_chars=genome.max_obs_chars, context_line=context_line,
                            skills=f"Preloaded functions:\n{skills}" if skills else "",
                            max_steps=genome.limits.max_steps, max_subcalls=genome.limits.max_subcalls)
    if genome.context_mode == "both":
        mode = MODE_INLINE + "\n\n" + mode
    return BASE_PROMPT.format(mode=mode, notes=notes)


def build_first_message(genome: Genome, task: Task) -> str:
    n_lines = task.context.count("\n") + 1
    if genome.context_mode == "repl":
        preview = "\n".join(task.context.splitlines()[:5])
        return (f"The dataset is in the REPL variable `context` ({n_lines} lines). Its first lines:\n{preview}\n\n"
                f"QUESTION: {task.question}")
    text = f"DATA ({n_lines} lines):\n{task.context}\n\nQUESTION: {task.question}"
    if genome.context_mode == "both":
        text += "\n\n(The same data is also in the REPL variable `context`.)"
    return text


def run_validators(validators: dict[str, str], answer: str, question: str) -> str | None:
    for name, src in validators.items():
        ns: dict = {}
        try:
            exec(src, ns)
            message = ns["check"](answer, question)
        except Exception:  # a broken validator never blocks an answer
            continue
        if message:
            return f"{name}: {message}"
    return None


def run_task(genome: Genome, task: Task, model: Any, step_timeout: float = config.STEP_TIMEOUT_S) -> RunResult:
    usage, trace = Usage(), []
    sub, sub_lock = {"n": 0}, threading.Lock()

    def llm_query(prompt: str) -> str:
        with sub_lock:
            if sub["n"] >= genome.limits.max_subcalls:
                raise RuntimeError(f"sub-call budget of {genome.limits.max_subcalls} exhausted")
            sub["n"] += 1
        text, _, u = model.generate(genome.sub_model, SUB_SYSTEM, [Turn("user", str(prompt))], genome.thinking_level)
        usage.add(genome.sub_model, u)
        return text

    def llm_query_batch(prompts: list[str]) -> list[str]:
        with ThreadPoolExecutor(max_workers=8) as ex:
            return list(ex.map(llm_query, list(prompts)))

    ns: dict = {"__name__": "__repl__"}
    if genome.repl:
        ns.update(llm_query=llm_query, llm_query_batch=llm_query_batch)
        if genome.context_mode != "inline":
            ns["context"] = task.context
        for name, src in genome.skills.items():
            try:
                exec(src, ns)
            except Exception as e:
                trace.append({"step": 0, "role": "harness", "text": f"skill {name} failed to load: {e}"})
    repl = Repl(ns, step_timeout)
    system = build_system(genome, task)
    history = [Turn("user", build_first_message(genome, task))]
    answer: str | None = None
    error: str | None = None
    rejections = 0
    steps = 0

    def ask(turns: list[Turn]) -> tuple[str, Any]:
        nonlocal steps
        steps += 1
        text, raw, u = model.generate(genome.root_model, system, turns, genome.thinking_level)
        usage.add(genome.root_model, u)
        trace.append({"step": steps, "role": "model", "text": clip(text, 3000)})
        return text, raw

    try:
        while steps < genome.limits.max_steps:
            text, raw = ask(history)
            history.append(Turn("model", text or "(empty reply)", raw))
            if usage.tokens_in + usage.tokens_out > config.TOKEN_CEILING:
                error = "token ceiling reached"
                break
            blocks = CODE_RE.findall(text) if genome.repl else []
            prose = CODE_RE.sub("", text)
            notes: list[str] = []
            if blocks:
                out = "".join(repl.run(b) for b in blocks)
                notes.append("OUTPUT:\n" + clip(out or "(no output)", genome.max_obs_chars))
            candidate = None
            var = FINAL_VAR_RE.search(prose) if genome.repl else None
            fin = FINAL_RE.search(prose)
            if var:
                if var.group(1) in ns:
                    candidate = str(ns[var.group(1)])
                else:
                    notes.append(f"FINAL_VAR: there is no REPL variable named {var.group(1)!r}.")
            elif fin and not blocks:
                candidate = fin.group(1)
            elif fin:
                notes.append("Your FINAL line was ignored because code ran in the same reply. Check the output, then answer.")
            if candidate is not None:
                complaint = run_validators(genome.validators, candidate, task.question)
                if complaint and rejections < MAX_VALIDATOR_REJECTIONS:
                    rejections += 1
                    notes.append(f"Answer rejected by validator {complaint}")
                else:
                    answer = candidate
                    break
            if not notes:
                notes.append("Reply with a ```python block to run code, or finish with a line 'FINAL: <answer>'."
                             if genome.repl else "Finish with a line 'FINAL: <answer>'.")
            observation = "\n\n".join(notes)
            history.append(Turn("user", observation))
            trace.append({"step": steps, "role": "user", "text": clip(observation, 3000)})
        if answer is None and error is None:
            last = history[-1]
            turns = (history[:-1] + [Turn("user", f"{last.text}\n\n{LIMIT_MESSAGE}")] if last.role == "user"
                     else history + [Turn("user", LIMIT_MESSAGE)])
            text, _ = ask(turns)
            fin = FINAL_RE.search(CODE_RE.sub("", text))
            answer = fin.group(1) if fin else ""
    except Exception as e:  # noqa: BLE001 — a provider failure ends this run, not the evaluation
        error = f"{type(e).__name__}: {e}"
    answer = (answer or "").strip()
    return RunResult(task_id=task.id, split=task.split, kind=task.kind, question=task.question,
                     expected=task.answer, answer=answer, score=score(task, answer),
                     tokens_in=usage.tokens_in, tokens_out=usage.tokens_out, cost=round(usage.cost(), 6),
                     steps=steps, subcalls=sub["n"], error=error, trace=trace)
````

```python
"""Runs each job in a fresh spawned process with its own wall-clock limit.

A hung, crashed or misbehaving task costs one job, never the evaluation.
"""
from __future__ import annotations

import importlib
import multiprocessing as mp
import time
from typing import Any, Callable


def _child(target: str, job: dict, conn) -> None:
    try:
        module, _, name = target.partition(":")
        result = getattr(importlib.import_module(module), name)(job)
        conn.send({"ok": True, "result": result})
    except BaseException as e:  # noqa: BLE001 — report everything, including SystemExit from model code
        conn.send({"ok": False, "error": f"{type(e).__name__}: {e}"})
    finally:
        conn.close()


def run_many(target: str, jobs: list[dict], max_parallel: int, timeout_s: float,
             on_done: Callable[[int, dict], None] | None = None) -> list[dict]:
    ctx = mp.get_context("spawn")
    results: list[dict | None] = [None] * len(jobs)
    pending = list(range(len(jobs)))
    running: dict[int, tuple[Any, Any, float]] = {}

    def finish(i: int, outcome: dict) -> None:
        results[i] = outcome
        running.pop(i)
        if on_done:
            on_done(i, outcome)

    while pending or running:
        while pending and len(running) < max_parallel:
            i = pending.pop(0)
            recv, send = ctx.Pipe(duplex=False)
            p = ctx.Process(target=_child, args=(target, jobs[i], send), daemon=True)
            p.start()
            send.close()
            running[i] = (p, recv, time.monotonic())
        for i, (p, recv, t0) in list(running.items()):
            if recv.poll():
                try:
                    outcome = recv.recv()
                except EOFError:
                    p.join(5)
                    outcome = {"ok": False, "error": f"worker exited with code {p.exitcode} before reporting"}
                p.join(5)
                finish(i, outcome)
            elif not p.is_alive():
                finish(i, {"ok": False, "error": f"worker exited with code {p.exitcode}"})
            elif time.monotonic() - t0 > timeout_s:
                p.kill()
                p.join()
                finish(i, {"ok": False, "error": f"timeout after {timeout_s:.0f}s"})
        time.sleep(0.05)
    return results  # type: ignore[return-value]
```

import os
import tempfile

from lamarck import llm

```python
"""MongoDB Atlas access.

Collections: genomes (the lineage tree), runs (one per genome x task, trace embedded),
feed (human-readable live log), meta (champion pointer per evolution run).
"""
from __future__ import annotations

import os
import time
import uuid
from datetime import datetime, timezone

from pymongo import ASCENDING, MongoClient

from lamarck import config

_db = None


def db():
    global _db
    if _db is None:
        client = MongoClient(os.environ["MONGODB_URI"], serverSelectionTimeoutMS=10_000, appname="lamarck")
        _db = client[config.DB_NAME]
        _db.genomes.create_index([("run", ASCENDING), ("generation", ASCENDING)])
        _db.runs.create_index([("genome_id", ASCENDING), ("split", ASCENDING)])
        _db.feed.create_index([("run", ASCENDING), ("ts", ASCENDING)])
    return _db


def ping() -> None:
    db().command("ping")


def insert_genome(run: str, genome: dict, parent_id: str | None, generation: int, *, ops: list | None = None,
                  hypothesis: str = "", diagnosis: str = "", focus: str = "", status: str = "candidate",
                  reason: str = "") -> str:
    gid = uuid.uuid4().hex[:8]
    db().genomes.insert_one({"_id": gid, "run": run, "parent_id": parent_id, "generation": generation,
                             "genome": genome, "ops": ops or [], "hypothesis": hypothesis, "diagnosis": diagnosis,
                             "focus": focus, "status": status, "reason": reason, "scores": {},
                             "created_at": datetime.now(timezone.utc)})
    return gid


def get_genome(gid: str) -> dict | None:
    return db().genomes.find_one({"_id": gid})


def set_status(gid: str, status: str, reason: str) -> None:
    db().genomes.update_one({"_id": gid}, {"$set": {"status": status, "reason": reason}})


def set_scores(gid: str, split: str, summary: dict) -> None:
    db().genomes.update_one({"_id": gid}, {"$set": {f"scores.{split}": summary}})


def champion(run: str) -> str | None:
    doc = db().meta.find_one({"_id": f"champion:{run}"})
    return doc["genome_id"] if doc else None


def set_champion(run: str, gid: str) -> None:
    db().meta.update_one({"_id": f"champion:{run}"}, {"$set": {"genome_id": gid}}, upsert=True)


def insert_runs(gid: str, split: str, results: list[dict]) -> None:
    now = datetime.now(timezone.utc)
    db().runs.insert_many([{**r, "genome_id": gid, "split": split, "created_at": now} for r in results])


def failing_runs(gid: str, split: str, limit: int) -> list[dict]:
    return list(db().runs.find({"genome_id": gid, "split": split, "score": {"$lt": 1.0}})
                .sort("score", ASCENDING).limit(limit))


def lineage(run: str) -> list[dict]:
    return list(db().genomes.find({"run": run}).sort([("generation", ASCENDING), ("created_at", ASCENDING)]))


def log(run: str, msg: str) -> None:
    db().feed.insert_one({"run": run, "ts": time.time(), "msg": msg})
    print(msg, flush=True)


def feed(run: str, after: float = 0.0, limit: int = 300) -> list[dict]:
    return list(db().feed.find({"run": run, "ts": {"$gt": after}}, {"_id": 0}).sort("ts", ASCENDING).limit(limit))

- [ ] **Step 3: Write `lamarck/evaluate.py`**

```python
"""Runs genomes over task splits in isolated workers and records every run in MongoDB."""
from __future__ import annotations

from collections import defaultdict

from lamarck import config, pool, store
from lamarck.harness import error_result
from lamarck.tasks import make_task


def summarize(results: list[dict]) -> dict:
    n = len(results)
    kinds: dict[str, list[float]] = defaultdict(list)
    for r in results:
        kinds[r["kind"]].append(r["score"])
    return {"acc": round(sum(r["score"] for r in results) / n, 4),
            "tokens": round(sum(r["tokens_in"] + r["tokens_out"] for r in results) / n),
            "cost": round(sum(r["cost"] for r in results), 4),
            "n": n,
            "errors": sum(1 for r in results if r.get("error")),
            "by_kind": {k: round(sum(v) / len(v), 3) for k, v in sorted(kinds.items())}}


def evaluate_many(pairs: list[tuple[str, str]], run: str | None = None) -> dict[tuple[str, str], dict]:
    jobs, keys = [], []
    for gid, split in pairs:
        genome = store.get_genome(gid)["genome"]
        for i in range(config.SPLITS[split][0]):
            jobs.append({"genome": genome, "split": split, "idx": i})
            keys.append((gid, split, i))
    done = {"n": 0}

    def progress(_i: int, _outcome: dict) -> None:
        done["n"] += 1
        if run and (done["n"] % 6 == 0 or done["n"] == len(jobs)):
            store.log(run, f"  evaluated {done['n']}/{len(jobs)} task runs")

    outcomes = pool.run_many("lamarck.worker:run_job", jobs, config.MAX_PARALLEL, config.TASK_TIMEOUT_S, on_done=progress)
    grouped: dict[tuple[str, str], list[dict]] = defaultdict(list)
    for (gid, split, i), o in zip(keys, outcomes):
        grouped[(gid, split)].append(o["result"] if o["ok"]
                                     else error_result(make_task(split, i), o["error"]).model_dump(mode="json"))
    summaries = {}
    for (gid, split), results in grouped.items():
        store.insert_runs(gid, split, results)
        summaries[(gid, split)] = summarize(results)
        store.set_scores(gid, split, summaries[(gid, split)])
    return summaries
```

```python
"""The acceptance rule, as pure functions.

A candidate must beat its parent on train (one more task right, or the same accuracy for at least 15%
fewer tokens), and must not lose more than one task's worth of accuracy on the held-out gate split.
"""
from __future__ import annotations

from dataclasses import dataclass

EPS = 1e-9
TOKEN_SAVING = 0.85


@dataclass(frozen=True)
class Score:
    acc: float
    tokens: float

    @classmethod
    def of(cls, summary: dict) -> "Score":
        return cls(summary["acc"], summary["tokens"])


@dataclass(frozen=True)
class Verdict:
    status: str  # accepted | rejected_no_gain | rejected_overfit
    reason: str


def train_passes(parent: Score, cand: Score, n_train: int) -> tuple[bool, str]:
    if cand.acc >= parent.acc + 1 / n_train - EPS:
        return True, f"train acc {parent.acc:.2f} -> {cand.acc:.2f}"
    if cand.acc >= parent.acc - EPS and cand.tokens <= TOKEN_SAVING * parent.tokens:
        return True, f"train acc held at {cand.acc:.2f}; tokens/task {parent.tokens:,.0f} -> {cand.tokens:,.0f}"
    return False, (f"no train gain: acc {parent.acc:.2f} -> {cand.acc:.2f}, "
                   f"tokens/task {parent.tokens:,.0f} -> {cand.tokens:,.0f}")


def gate_verdict(p_train: Score, c_train: Score, p_gate: Score, c_gate: Score, n_train: int, n_gate: int) -> Verdict:
    detail = f"gate acc {p_gate.acc:.2f} -> {c_gate.acc:.2f}"
    if c_gate.acc >= p_gate.acc - 1 / n_gate - EPS:
        return Verdict("accepted", detail)
    if c_train.acc - p_train.acc >= 2 / n_train - EPS:
        return Verdict("rejected_overfit", f"train gain {c_train.acc - p_train.acc:+.2f} did not hold out: {detail}")
    return Verdict("rejected_no_gain", f"gate regression: {detail}")
```

```markdown
You are the harness engineer of Lamarck, a self-improving agent harness.

A worker model answers questions about large production log dumps. It runs inside a harness whose whole behaviour is set by a JSON genome. Your job: read how the current champion genome failed, then propose ONE patch (a short list of operations) that you expect to raise accuracy on unseen tasks of the same kinds, or to keep accuracy while cutting tokens per task.

How the harness works (fixed; you cannot change it):
- Each reply of the worker is either a ```python block, run in a persistent REPL whose printed output (cut to max_obs_chars) comes back as the next message, or a final line 'FINAL: <answer>' or 'FINAL_VAR(name)'.
- The base prompt, the scorer, the task data and the hard caps are fixed.
- Accuracy is measured on train tasks, whose failures you see, AND on held-out tasks you never see. A patch that encodes specific answers, ids or counts will fail the held-out gate and be rejected as overfit.

Genes you can change:
- root_model, sub_model: worker model ids. Allowed: {models}.
- thinking_level: one of {levels}. Higher means more reasoning tokens.
- repl: if true, the worker has a persistent Python REPL (standard library only) with llm_query(prompt) -> str and llm_query_batch(prompts) -> list[str], which call sub_model; a sub-model sees only the prompt it is given.
- context_mode: "inline" puts the data in the first message; "repl" puts it only in the REPL variable `context` and shows the worker a short preview (needs repl=true); "both" does both.
- max_obs_chars (200 to 50000): how much REPL output re-enters the worker's context.
- limits.max_steps (1 to 30) and limits.max_subcalls (0 to 200).
- system_notes: rules appended to the worker's system prompt (at most 12, each at most 500 characters).
- skills: Python functions preloaded into the REPL (at most 8; each source at most 6000 characters; it must define a top-level function with the skill's name, with a docstring whose first line is shown to the worker; it may call llm_query and llm_query_batch).
- validators: Python source defining check(answer: str, question: str) -> str or None. A returned string rejects the final answer and is shown to the worker, at most twice per task.

Operations:
- set: path is one of {paths}; value_json is the JSON-encoded value, for example true, "repl" or 8000.
- add_note (text), remove_note (index)
- put_skill (name, source), del_skill (name)
- put_validator (name, source), del_validator (name)

How to work:
- Diagnose from the traces first, and name the failure mechanism in your diagnosis.
- Prefer a small, testable patch of one to four operations.
- Read the lineage: do not repeat a rejected idea unless you have a new reason, and say what it is.
- Tokens cost money, and long contexts are expensive.
```

```python
"""The harness engineer: reads the champion's failures and proposes one typed patch (Opus via Claude Code)."""
from __future__ import annotations

import json
from pathlib import Path
from typing import Callable

from pydantic import ValidationError

from lamarck import config, llm
from lamarck.genome import OP_NAMES, SETTABLE, Genome, Op, PatchError, apply

MANUAL = (Path(__file__).parent / "prompts" / "engineer.md").read_text()

FOCI = {
    "accuracy": "Fix the most common failure mechanism you see in the failing runs.",
    "cost": "Keep accuracy at least as high while cutting tokens per task.",
    "free": "Make the change you believe will most improve accuracy on unseen tasks, including a larger architectural change.",
}

PROPOSAL_SCHEMA = {
    "type": "object", "additionalProperties": False, "required": ["diagnosis", "hypothesis", "ops"],
    "properties": {
        "diagnosis": {"type": "string"},
        "hypothesis": {"type": "string"},
        "ops": {"type": "array", "minItems": 1, "maxItems": 8, "items": {
            "type": "object", "additionalProperties": False, "required": ["op"],
            "properties": {"op": {"type": "string", "enum": list(OP_NAMES)}, "path": {"type": "string"},
                           "value_json": {"type": "string"}, "text": {"type": "string"},
                           "index": {"type": "integer"}, "name": {"type": "string"},
                           "source": {"type": "string"}}}}},
}


def manual() -> str:
    return MANUAL.format(models=", ".join(sorted(config.WORKER_MODELS)), levels=", ".join(config.THINKING_LEVELS),
                         paths=", ".join(sorted(SETTABLE)))


def _clip(s: str, n: int) -> str:
    return s if len(s) <= n else s[: n // 2] + "\n...\n" + s[-n // 2:]


def describe_ops(ops: list[dict]) -> str:
    parts = []
    for o in ops:
        if o["op"] == "set":
            parts.append(f"set {o['path']}={o['value_json']}")
        elif o["op"] == "add_note":
            parts.append(f"add_note {o['text'][:80]!r}")
        elif o["op"] == "remove_note":
            parts.append(f"remove_note #{o['index']}")
        else:
            parts.append(f"{o['op']} {o['name']}")
    return "; ".join(parts) or "(none)"


def build_prompt(champ: dict, failures: list[dict], history: list[dict], focus: str) -> str:
    train = champ["scores"]["train"]
    parts = [f"## Focus\n{FOCI[focus]}",
             f"## Champion genome {champ['_id']} (generation {champ['generation']})\n```json\n"
             f"{json.dumps(champ['genome'], indent=2)}\n```",
             f"## Champion on train\naccuracy {train['acc']:.2f} over {train['n']} tasks; by kind {train['by_kind']}; "
             f"{train['tokens']} tokens per task; ${train['cost']:.3f} total; {train['errors']} errors",
             f"## Failing train runs ({len(failures)} shown)"]
    for r in failures:
        steps = r.get("trace", [])
        shown = steps[:1] + (steps[-4:] if len(steps) > 5 else steps[1:])
        trace = "\n".join(f"[{s['role']} {s['step']}] {_clip(s['text'], 1200)}" for s in shown)
        parts.append(f"### {r['task_id']} ({r['kind']}), score {r['score']}\nQuestion: {r['question']}\n"
                     f"Expected: {r['expected']}\nGot: {r['answer'][:300]!r}\nError: {r.get('error')}\n"
                     f"Steps: {r['steps']}, sub-calls: {r['subcalls']}, tokens: {r['tokens_in'] + r['tokens_out']}\n"
                     f"Trace (first and last steps):\n{trace or '(no steps recorded)'}")
    tried = [g for g in history if g.get("parent_id")]
    parts.append("## Lineage so far (oldest first)\n" + ("\n".join(
        f"- gen {g['generation']} {g['_id']} [{g.get('focus', '')}] {describe_ops(g.get('ops', []))} -> "
        f"{g['status']}: {g.get('reason', '')} (train acc {g.get('scores', {}).get('train', {}).get('acc', '?')})"
        for g in tried) or "(no patches tried yet)"))
    parts.append("Propose one patch now.")
    return "\n\n".join(parts)


def propose(champ: dict, failures: list[dict], history: list[dict], focus: str,
            call: Callable[[str, str, dict], dict] = llm.claude_json) -> dict:
    prompt = build_prompt(champ, failures, history, focus)
    error: str | None = None
    out: dict = {}
    for _ in range(2):
        attempt = prompt if error is None else (f"{prompt}\n\n## Your previous proposal was invalid\n{error}\n"
                                                "Fix it and propose again.")
        try:
            out = call(attempt, manual(), PROPOSAL_SCHEMA)
            ops = [Op.model_validate(o) for o in out["ops"]]
            child = apply(Genome.model_validate(champ["genome"]), ops)
            return {"ok": True, "genome": child.model_dump(), "ops": [o.model_dump(exclude_none=True) for o in ops],
                    "hypothesis": out.get("hypothesis", ""), "diagnosis": out.get("diagnosis", "")}
        except (llm.EngineerError, PatchError, ValidationError, KeyError, TypeError) as e:
            error = str(e)[:1500]
    return {"ok": False, "error": error or "unknown error", "hypothesis": out.get("hypothesis", ""),
            "diagnosis": out.get("diagnosis", "")}
```

```python
"""Lamarck CLI: evolve | long | status | rollback | ping."""
from __future__ import annotations

import argparse
from concurrent.futures import ThreadPoolExecutor

from lamarck import config, engineer, gate, store
from lamarck.evaluate import evaluate_many
from lamarck.genome import GEN0


def ensure_root(run: str) -> str:
    gid = store.champion(run)
    if gid:
        return gid
    gid = store.insert_genome(run, GEN0.model_dump(), None, 0, status="accepted",
                              reason="generation 0: plain inline harness")
    store.set_champion(run, gid)
    store.log(run, f"created generation 0 ({gid})")
    return gid


def ensure_scores(run: str, gid: str, splits: tuple[str, ...] = ("train", "gate")) -> dict:
    missing = [(gid, s) for s in splits if s not in store.get_genome(gid).get("scores", {})]
    if missing:
        store.log(run, f"evaluating {gid} on {', '.join(s for _, s in missing)}")
        evaluate_many(missing, run)
    return store.get_genome(gid)


def generation(run: str, g: int, k: int) -> None:
    champ = ensure_scores(run, ensure_root(run))
    failures = store.failing_runs(champ["_id"], "train", limit=6)
    history = store.lineage(run)[-12:]
    foci = list(engineer.FOCI)[:k]
    store.log(run, f"gen {g}: engineer reading {len(failures)} failing runs of champion {champ['_id']} "
                   f"(train acc {champ['scores']['train']['acc']:.2f}); foci: {', '.join(foci)}")
    with ThreadPoolExecutor(len(foci)) as ex:
        proposals = list(ex.map(lambda f: engineer.propose(champ, failures, history, f), foci))
    cands = []
    for focus, p in zip(foci, proposals):
        if not p["ok"]:
            store.insert_genome(run, champ["genome"], champ["_id"], g, hypothesis=p["hypothesis"],
                                diagnosis=p["diagnosis"], focus=focus, status="invalid", reason=p["error"][:500])
            store.log(run, f"gen {g} [{focus}] invalid proposal: {p['error'][:160]}")
            continue
        gid = store.insert_genome(run, p["genome"], champ["_id"], g, ops=p["ops"], hypothesis=p["hypothesis"],
                                  diagnosis=p["diagnosis"], focus=focus)
        cands.append(gid)
        store.log(run, f"gen {g} [{focus}] {gid}: {engineer.describe_ops(p['ops'])} | {p['hypothesis'][:220]}")
    if not cands:
        store.log(run, f"gen {g}: no valid proposals")
        return
    sums = evaluate_many([(c, "train") for c in cands], run)
    n_train, n_gate = config.SPLITS["train"][0], config.SPLITS["gate"][0]
    parent_train = gate.Score.of(champ["scores"]["train"])
    ranked = sorted(cands, key=lambda c: (sums[(c, "train")]["acc"], -sums[(c, "train")]["tokens"]), reverse=True)
    for c in ranked:
        s = sums[(c, "train")]
        store.log(run, f"gen {g} {c}: train acc {s['acc']:.2f} {s['by_kind']}, {s['tokens']:,} tok/task, ${s['cost']:.3f}")
    best = ranked[0]
    for c in ranked[1:]:
        ok, why = gate.train_passes(parent_train, gate.Score.of(sums[(c, "train")]), n_train)
        store.set_status(c, "not_selected" if ok else "rejected_no_gain", why)
    ok, why = gate.train_passes(parent_train, gate.Score.of(sums[(best, "train")]), n_train)
    if not ok:
        store.set_status(best, "rejected_no_gain", why)
        store.log(run, f"gen {g}: no candidate beat the champion ({why})")
        return
    gate_sum = evaluate_many([(best, "gate")], run)[(best, "gate")]
    v = gate.gate_verdict(parent_train, gate.Score.of(sums[(best, "train")]), gate.Score.of(champ["scores"]["gate"]),
                          gate.Score.of(gate_sum), n_train, n_gate)
    store.set_status(best, v.status, f"{why}; {v.reason}")
    if v.status == "accepted":
        store.set_champion(run, best)
    store.log(run, f"gen {g}: {best} {v.status.upper()} ({why}; {v.reason})")


def cmd_evolve(a: argparse.Namespace) -> None:
    ensure_root(a.run)
    start = max(x["generation"] for x in store.lineage(a.run)) + 1
    for g in range(start, start + a.gens):
        generation(a.run, g, a.candidates)


def cmd_long(a: argparse.Namespace) -> None:
    ids = list(dict.fromkeys([store.lineage(a.run)[0]["_id"], store.champion(a.run)]))
    for gid in ids:
        ensure_scores(a.run, gid, ("long",))
    for gid in ids:
        s = store.get_genome(gid)["scores"]["long"]
        store.log(a.run, f"long split: {gid} acc {s['acc']:.2f} {s['by_kind']}, {s['tokens']:,} tok/task, ${s['cost']:.3f}")


def cmd_status(a: argparse.Namespace) -> None:
    champ = store.champion(a.run)
    for x in store.lineage(a.run):
        sc = x.get("scores", {})
        acc = {s: sc.get(s, {}).get("acc", "-") for s in ("train", "gate", "long")}
        print(f"{'*' if x['_id'] == champ else ' '} g{x['generation']:<2} {x['_id']} {x['status']:<17} "
              f"train={acc['train']} gate={acc['gate']} long={acc['long']}  {engineer.describe_ops(x.get('ops', []))[:90]}")


def cmd_rollback(a: argparse.Namespace) -> None:
    g = store.get_genome(a.to)
    if not g or g["run"] != a.run or g["status"] != "accepted":
        raise SystemExit(f"{a.to} is not an accepted genome of run {a.run!r}")
    store.set_champion(a.run, a.to)
    store.log(a.run, f"rollback: champion is now {a.to}")


def cmd_ping(_a: argparse.Namespace) -> None:
    store.ping()
    print("ping ok")


def main(argv: list[str] | None = None) -> None:
    ap = argparse.ArgumentParser(prog="lamarck")
    sub = ap.add_subparsers(dest="cmd", required=True)
    for name, fn in (("evolve", cmd_evolve), ("long", cmd_long), ("status", cmd_status),
                     ("rollback", cmd_rollback), ("ping", cmd_ping)):
        p = sub.add_parser(name)
        p.set_defaults(fn=fn)
        if name != "ping":
            p.add_argument("--run", default="main")
        if name == "evolve":
            p.add_argument("--gens", type=int, default=1)
            p.add_argument("--candidates", type=int, default=3, choices=[1, 2, 3])
        if name == "rollback":
            p.add_argument("--to", required=True)
    a = ap.parse_args(argv)
    a.fn(a)


if __name__ == "__main__":
    main()
```

```python
"""Live view of an evolution run: lineage tree, per-genome detail and the feed, read from MongoDB."""
from pathlib import Path

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse

from lamarck import store

STATIC = Path(__file__).parent / "static"
app = FastAPI(title="Lamarck")


@app.get("/")
def index() -> FileResponse:
    return FileResponse(STATIC / "index.html")


@app.get("/api/run/{run}")
def run_view(run: str) -> dict:
    return {"run": run, "champion": store.champion(run), "genomes": store.lineage(run)}


@app.get("/api/genome/{gid}")
def genome_view(gid: str) -> dict:
    g = store.get_genome(gid)
    if not g:
        raise HTTPException(404, f"no genome {gid}")
    return {"genome": g, "parent": store.get_genome(g["parent_id"]) if g.get("parent_id") else None}


@app.get("/api/run/{run}/feed")
def feed_view(run: str, after: float = 0.0) -> list[dict]:
    return store.feed(run, after)
```

function drawTree(genomes, champion) {
  const byGen = {};

function drawCurve(genomes, champion) {
  const byId = Object.fromEntries(genomes.map((g) => [g._id, g]));
  const path = []; let cur = byId[champion];
  while (cur) { path.unshift(cur); cur = byId[cur.parent_id]; }
  const pts = path.filter((g) => g.scores?.train);
  const svg = $("curve"); const W = svg.clientWidth || 600, H = 140, P = 28;
  if (!pts.length) { svg.innerHTML = ""; return; }
  const maxGen = Math.max(1, ...pts.map((g) => g.generation)), maxTok = Math.max(...pts.map((g) => g.scores.train.tokens));
  const X = (gen) => P + (W - 2 * P) * gen / maxGen, Y = (v) => H - P - (H - 2 * P) * v;
  const line = (f, color) => `<polyline fill="none" stroke="${color}" stroke-width="2.5" points="${pts.map((g) => `${X(g.generation)},${Y(f(g))}`).join(" ")}"/>` +
    pts.map((g) => `<circle cx="${X(g.generation)}" cy="${Y(f(g))}" r="3.5" fill="${color}"/>`).join("");
  svg.innerHTML = `<line x1="${P}" x2="${W - P}" y1="${H - P}" y2="${H - P}" stroke="#30363d"/>` +
    line((g) => g.scores.train.acc, "var(--accepted)") + line((g) => g.scores.train.tokens / maxTok, "var(--pending)") +
    `<text x="${P}" y="14" style="fill:var(--accepted)">accuracy</text><text x="${P + 80}" y="14" style="fill:var(--pending)">tokens/task (relative)</text>` +
    pts.map((g) => `<text x="${X(g.generation)}" y="${H - 8}" text-anchor="middle" style="fill:var(--muted)">${g.generation}</text>`).join("");
}
